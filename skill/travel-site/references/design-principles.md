# Design principles

Existing confirmed/locked UI wins. Do not redesign just because an Agent is capable of doing so.

For a genuinely new visual direction, derive three materially distinct modes from destination, season, trip tone, and sharing context:
1. `sensory` — image/atmosphere-led.
2. `editorial` — typography/content-led.
3. `navigator` — route/checklist-led.

A design should differ structurally, not only by color. Keep text contrast readable and mobile travel controls large enough for one-handed use. Destination identity can influence palette, typography, texture, and motif, but cultural decoration must remain subordinate to itinerary usability.
